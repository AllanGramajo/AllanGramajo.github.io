## Heart and Chest Radar

**[Open the interactive radar website](https://allangramajo.github.io/Heart-and-Chest-radar/)** — a shared project by **Allan Gramajo and Alan Acosta**, equal contributors. Choose among eight included public radar recordings and replay the measured signals directly in the browser. No GitHub account or CSV download is required. [Project README and data provenance](Heart-and-Chest-radar/README.md).

The radar page is separate from the portfolio homepage, which remains unchanged.
